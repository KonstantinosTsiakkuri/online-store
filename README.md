# Online Store OOP Project

Проект интернет-магазина, написанный на Python с использованием принципов объектно-ориентированного программирования (ООП).

## Реализованный функционал
* Базовые классы продуктов и категорий товаров.
* Наследование: создание специфичных товаров (Смартфоны, Газонная трава).
* Абстрактные классы (ABC) для унификации интерфейсов.
* Использование миксинов для логирования создания объектов.
* Магические методы (`__add__`, `__str__`, `__repr__`).

## Технологии
* Python 3.x
* Poetry (управление зависимостями)
* Pytest (покрытие кода автотестами)
